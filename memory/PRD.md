# CarBridge - Платформа для импорта авто из Китая

**Последнее обновление:** 28.03.2026

## Оригинальное техзадание
Комплексная платформа для импорта автомобилей из Китая в Беларусь с интеграцией Bitrix24 CRM.

**Роли:** Администратор, Клиент, Подрядчик, Модератор.

**Бренд-концепция:** "Мы не продаём автомобили — мы соединяем доверие и выгоду". CarBridge — мост доверия между покупателем и автомобилем.

## Текущая архитектура
- FastAPI backend, React frontend, MongoDB
- Модульные роуты: catalog.py, telegram.py, deals.py, auth.py, affiliate.py, user.py, leasing.py
- server.py: ~6950 строк (уменьшено с ~8990)
- Shared config: config.py (константы), database.py, utils/auth.py

### ✅ Баг: Цена для Беларуси не рассчитывалась при добавлении авто в гараж

**Решение**: Проверено и подтверждено, что функция `calculate_customs()` корректно вызывается в эндпоинте `POST /api/garage`. Тестирование показало:

- ДВС авто: `calculated_price_usd: 34215.71`, `calculated_price_byn: 100019.37`

**Статус**: ✅ Работает (протестировано 13/13 тестов)

### ✅ Баг: bcrypt warning в логах
**Проблема**: `AttributeError: module 'bcrypt' has no attribute '__about__'` появлялась при каждой операции аутентификации.

**Причина**: Несовместимость passlib 1.7.4 с bcrypt 4.x (passlib пытается получить версию через `bcrypt.__about__.__version__`, которого нет в bcrypt 4.x).

**Решение**: Добавлено подавление предупреждения через:
```python
logging.getLogger("passlib.handlers.bcrypt").setLevel(logging.ERROR)
```
в файлах `/app/backend/server.py` и `/app/backend/utils/auth.py`.

**Статус**: ✅ Исправлено (предупреждения больше не появляются)

### ✅ Баг: "Автомобиль не найден" при добавлении авто из тендера в сделку
**Проблема**: При принятии предложения подрядчика по тендеру (созданному из заявки) и добавлении в сделку возникала ошибка "Автомобиль не найден".

**Причина**: Когда тендер создаётся из заявки (не из гаража), у него нет `car_id` и `car_info` - только `car_request` с параметрами желаемого авто. Эндпоинт `/deals/add-car` искал авто только в гараже.

**Решение** в `/app/backend/server.py`:
1. Если `car_id` не найден в гараже и это тендер, получаем данные из предложения подрядчика (`tender_offers`)
2. Дополняем данные о марке/модели из `car_request` тендера
3. Создаём запись в гараже автоматически из данных предложения
4. Обновлён фронтенд `/app/frontend/src/pages/dashboard/Tenders.js` - передаётся `tender_id`

**Статус**: ✅ Работает (авто из тендерного предложения успешно добавляется в сделку)

### ✅ Баг: Подрядчики не отображались при выборе для этапа "Доставка до порта (Китай)"
**Проблема**: При выборе подрядчика для этапа "Доставка до порта (Китай)" список подрядчиков был пустым.

**Причины**:
1. Фильтрация подрядчиков искала `services.includes('logistics')`, но у подрядчиков услуги указаны как `logistics_china`
2. Кнопка "Выбрать подрядчика" показывалась только для текущего этапа (`isCurrent`), а не для всех pending этапов
3. Если `contractor_id` был установлен, но `price = 0`, статус считался `contractor_selected` и кнопка не показывалась

**Решение** в `/app/frontend/src/pages/dashboard/DealCars.js`:
1. Расширена фильтрация подрядчиков для всех этапов (logistics_china, delivery_rb, customs, inspection, export)
2. Убрано условие `isCurrent` - кнопки показываются для всех pending этапов
3. Статус `contractor_selected` возвращается только если `contractor_id && price > 0`

**Статус**: ✅ Работает (подрядчики отображаются для всех этапов)

### ✅ Баг: Каталог - не отображались параметры авто и не рассчитывалась цена
**Проблема**: В карточках каталога не показывались год, цена, объём двигателя. При добавлении авто из каталога в гараж не рассчитывалась цена для Беларуси.

**Причины**:
1. Frontend использовал `car.year` и `car.price` вместо `car.year_from` и `car.price_from_cny`
2. Объём двигателя показывался в мл вместо литров (1600 вместо 1.6L)
3. Эндпоинт `POST /api/catalog/{car_id}/add-to-garage` не вызывал функцию расчёта таможенных платежей
4. Поле `images` от API возвращалось как JSON-строка, а не массив

**Решение**:
1. Исправлен Frontend `/app/frontend/src/pages/dashboard/Catalog.js`:
   - `car.year_from || car.year` для года
   - `car.price_from_cny || car.price` для цены
   - `car.engine_volume / 1000` для объёма в литрах
2. Добавлен расчёт цены в `/app/backend/routes/catalog.py`:
   - Импортирован `calculate_customs_price` из `services.calculator`
   - Добавлен вызов расчёта при добавлении из каталога
   - Исправлен парсинг `images` JSON-строки
3. Добавлен proxy для китайских CDN в `/app/frontend/src/pages/dashboard/MyGarage.js`

**Статус**: ✅ Работает (карточки отображают все параметры, цена рассчитывается, изображения загружаются)
