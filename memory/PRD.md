# CarBridge - Платформа для импорта авто из Китая

## Оригинальное техзадание
Комплексная платформа для импорта автомобилей из Китая в Беларусь. Включает:
- Главная страница с каталогом, калькулятором, AI-ассистентом
- Личный кабинет пользователя: гараж, заявки, тендеры, сделки, верификация
- Панель модератора: управление пользователями, документами, сделками
- Система подрядчиков: регистрация, дашборд

## Роли пользователей
- **user**: Обычный пользователь
- **moderator**: Модератор для проверки документов и сделок
- **admin**: Полный доступ (test@test.com / test)
- **contractor**: Подрядчик (все существующие подрядчики имеют пароль `contractor123`)

## Текущая архитектура

### Backend
- **Framework**: FastAPI
- **Database**: MongoDB
- **Auth**: JWT токены (отдельные для пользователей и подрядчиков)
- **File**: `/app/backend/server.py` (~6000+ строк)

### Frontend
- **Framework**: React
- **Styling**: Tailwind CSS + Shadcn UI
- **State**: React Context (AuthContext)

## Ключевые API эндпоинты

### Каталог автомобилей (Che168)
- `GET /api/catalog/search` - Поиск авто (brand, model, min/max_price, min/max_year, engine_type, body_type)
- `GET /api/catalog/brands` - Список всех марок
- `GET /api/catalog/models/{brand}` - Модели для марки
- `GET /api/catalog/{car_id}` - Детали авто
- `POST /api/catalog/{car_id}/add-to-garage` - Добавить в гараж

### Заявки на подбор
- `POST /api/applications/create` - Создание заявки (новая расширенная схема ~70 полей)
- `GET /api/applications/my` - Список заявок пользователя
- `GET /api/applications/{id}` - Детали заявки
- `DELETE /api/applications/{id}` - Отмена заявки
- `POST /api/applications/{id}/request-manager-help` - Запрос помощи менеджера ($200)
- `POST /api/applications/{id}/start-tender` - Запуск тендера

### Сделки
- `POST /api/deals/{id}/skip-stage` - Пропуск этапа
- `POST /api/deals/{id}/pay-stage` - Оплата этапа
- `POST /api/deals/{id}/select-contractor` - Выбор подрядчика
- `GET /api/tracking/{id}` - GPS-отслеживание

### Подрядчики
- `POST /api/contractors/register` - Регистрация
- `POST /api/contractors/login` - Вход
- `GET /api/contractor-dashboard` - Дашборд
