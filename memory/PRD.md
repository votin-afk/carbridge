# CARBRIDGE MVP - Product Requirements Document

## Оригинальная постановка задачи
Автоплатформа с тендером для подбора и доставки автомобилей из Китая в Республику Беларусь. Платформа решает проблемы непрозрачности цен, рисков мошенничества и отсутствия контроля при импорте авто из Китая.

## Архитектура
- **Frontend**: React 19 + Tailwind CSS + Shadcn/UI
- **Backend**: FastAPI + MongoDB (Motor async driver)
- **AI**: OpenAI GPT-4o через Emergent LLM Key
- **Аутентификация**: JWT токены
- **Парсер данных**: BeautifulSoup4 + httpx (синхронизация с demo.pro-auctions.ru)

## User Personas
1. **Физическое лицо** - хочет купить авто для личного использования
2. **Юридическое лицо** - закупка авто для компании/автопарка
3. **Льготные категории** - многодетные семьи, инвалиды I-II гр. (Указ 140)

## Основные требования (Static)

### Landing Page
- Hero секция с основным CTA
- **AI-агент подбора авто** (интегрирован на главную страницу)
- Процесс работы (6 шагов)
- Преимущества платформы
- Площадки для поиска авто в Китае (58.com, che168.com, guazi.com, dongchedi.com)
- FAQ аккордеон
- Контакты

### Каталог авто (ОБНОВЛЕНО - Feb 2026)
- **Синхронизация с demo.pro-auctions.ru** (273 бренда, 256k+ авто)
- Живые данные: цены в юанях (¥), пробег, год выпуска
- **Изображения с оригинального источника** (cn.pa-server.ru)
- **Расширенные фильтры**: марка, модель, двигатель, кузов, год от/до, цена от/до
- **Умное определение типа двигателя** (ДВС/Гибрид/Электро по powerElectro/powerDVS)
- **Карточки загружаются только по запросу** (не при первоначальной загрузке)
- Добавление авто в гараж прямо из каталога
- Метки LIVE на карточках с актуальными данными
- Кэширование данных на 5 минут
- Fallback на статические данные при недоступности источника

### Калькулятор растаможки
- Расчет для физ. и юр. лиц
- Учет типа двигателя (ДВС, гибрид, электро)
- Учет возраста авто
- **Льгота по Указу 140** (50% скидка для льготных категорий физлиц)
- **Комиссия платформы 3%**
- **Комиссия за оплату 1.5%**
- Актуальные ставки таможенных пошлин РБ
- Фиксированные расходы (доставка, оформление)

### Личный кабинет
- Dashboard с обзором
- **Мой гараж** (сохраненные авто) с AI-парсингом URL
- Тендеры (предложения подрядчиков)
- Документы

### AI-функции
- AI-агент на главной странице для подбора авто
- **AI-парсинг URL** с китайских площадок (che168, 58.com, guazi, dongchedi)

## Технические заметки
- EMERGENT_LLM_KEY используется для AI чата и парсинга
- Mock данные для предложений подрядчиков (generate_mock_offers)
- Курсы валют кэшируются на 1 час
- Указ 140 даёт 50% скидку только физлицам на пошлины и НДС
- AI-парсинг работает лучше с dongchedi.com, китайские сайты могут блокировать запросы
- **Каталог парсится с demo.pro-auctions.ru, кэш 5 минут**
- **ProAuctionsParser** в server.py обрабатывает HTML с BeautifulSoup
