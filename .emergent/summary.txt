*   **System Roles:** Administrator, Client, Contractor, Moderator.
*   **Client Workflow:**
    1.  **Registration:** Form must include First Name, Last Name, City, Phone, Email, Referral Code, and Password. A new contact card should be created in Bitrix24 upon registration.
    2.  **My Garage:** Clients add cars from the catalog, by URL, or manually. Adding a car must automatically calculate its final cost in Belarus. The car card should have buttons: Add to Deal, Start Tender, Request Manager Help.
    3.  **Verification & Prepayment:** To unlock deals/tenders, clients must:
        *   Complete verification by providing passport data and uploading scans.
        *   Agree to a contract (via checkbox).
        *   Make a 00 prepayment (manually confirmed by a moderator after a bank transfer).
    4.  **Applications:** When creating an application for a car, a link to a specific car is a mandatory field.
    5.  **Manager Help:** Requesting help creates a dedicated chat with a manager in the Documents section, with file sharing capabilities. This interaction should be mirrored in Bitrix24.
    6.  **Deal Creation & Contractor Assignment:** Adding a car to a deal creates a structured deal in the Documents section. Clients can assign contractors to specific deal stages (from a list). Assignment triggers a notification to the contractor and opens a private chat. The deal structure should be created in Bitrix24.
    7.  **Documents Section:** This is the central hub for a deal, showing all stages. Each stage has a chat with the assigned contractor, a Complete Stage button, and an Update Cost button. Stage completion must be approved by a moderator before the client can pay for that stage.
    8.  **Tender Process:** Launching a tender sends the application details to all contractors. Contractor offers (including photos, videos, description, price, and included deal stages) are displayed as cards. Accepting an offer assigns the contractor to the relevant stages.
*   **Contractor Workflow:**
    *   Register and specify services offered. Must be approved by a moderator.
    *   Submit detailed offers on tenders.
    *   Communicate with clients via deal-specific chats.
    *   Place offers in a Hot Deals section on the main page.
*   **Moderator Workflow:**
    *   Approve new contractors.
    *   Manually confirm the 00 prepayment from clients.
    *   Approve each completed deal stage to unlock payment for the client.
    *   Full access to edit/delete information across the site and user profiles.
*   **Bitrix24 Integration:**
    *   Create a contact on user registration.
    *   Create a deal when a client initiates a deal structure.
    *   Create sections corresponding to deal stages.
    *   Mirror moderator actions (like stage approval) in Bitrix24.
    *   Use Bitrix Live Chat for manager-client communication.
